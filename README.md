# 🏃 Calculadora TACF

Uma ferramenta independente desenvolvida para auxiliar na análise de desempenho no **Teste de Aptidão de Condicionamento Físico (TACF)**.

O sistema permite inserir os índices obtidos nos diferentes exercícios e visualizar de forma rápida a situação do desempenho, facilitando a identificação dos pontos que podem ser aprimorados.

> **⚠️ Projeto independente:** esta ferramenta não possui vínculo oficial com órgãos, instituições ou entidades responsáveis pela aplicação do TACF.

---

## 🎯 Objetivo

A Calculadora TACF foi desenvolvida com o objetivo de facilitar a interpretação dos resultados obtidos nos testes físicos.

Através dos índices informados pelo usuário, o sistema apresenta informações que permitem:

* 📊 visualizar o desempenho obtido;
* 🎯 identificar os índices necessários para alcançar determinados níveis de desempenho;
* 📈 visualizar possibilidades de evolução;
* 🏃 acompanhar diferentes modalidades do teste;
* ⚡ obter os resultados de forma rápida e intuitiva.

---

## 🧮 Como utilizar

1. Acesse a calculadora.
2. Informe seus dados nos campos correspondentes.
3. Insira os índices obtidos em cada exercício.
4. O sistema realizará os cálculos automaticamente.
5. Consulte os resultados apresentados para identificar onde existe possibilidade de evolução.

---
